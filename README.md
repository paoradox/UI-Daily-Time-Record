# UI-Daily-Time-Record — Daily Time Record UI

[![Website](https://img.shields.io/badge/website-live-02aaff?style=for-the-badge&logo=githubpages)](https://paoradox.github.io/UI-Daily-Time-Record/)
[![Built with](https://img.shields.io/badge/built_with-HTML%2FCSS-02aaff?style=for-the-badge&logo=html5)](https://developer.mozilla.org/)

A clean, modern user interface design for a Daily Time Record (DTR) system, created to provide a streamlined experience for tracking employee attendance and work hours.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| **Clean Interface** | Simple, intuitive layout for efficient daily time entry and viewing |
| **Modern Aesthetics** | Contemporary design language for a professional look |
| **Responsive Layout** | Adapts seamlessly to desktop, tablet, and mobile screens |
| **Visual Feedback** | Hover effects and interactive elements enhance user experience |
| **No External Dependencies** | Pure HTML and CSS — no frameworks or libraries required |

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Edge, Safari)
- (Optional) A code editor (VS Code recommended)

### Local Development
1. **Clone the repository**
   ```bash
   git clone https://github.com/paoradox/UI-Daily-Time-Record.git
   cd UI-Daily-Time-Record
   ```

2. **Open with Live Server** (VS Code)
   - Right‑click `index.html` → "Open with Live Server"
   - Or simply double‑click `index.html` to open directly in your browser

3. **Visit** `http://localhost:5500` (or the browser tab)
